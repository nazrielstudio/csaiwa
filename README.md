# Cikeas FC Base Website

Website base club bola berbasis Next.js 14 + React 18. Ringan, responsive, tanpa library UI eksternal.

## Jalankan
```bash
npm install
npm run dev
```
Buka http://localhost:3000

## Build production
```bash
npm run build
npm start
```

## Yang perlu diganti
- Nomor WhatsApp di `app/page.tsx`
- Logo/identitas di `components/Navbar.tsx`
- Jadwal, berita, dan data club di `app/page.tsx`
